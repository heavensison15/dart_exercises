## Scenario

This program demonstrates a simple student snack purchase using variables, data types, arithmetic operators, comparison operators, and console output in Dart.

## Data Types Used

- `String` – student name
- `int` – snack quantity
- `double` – snack price and calculated amounts
- `bool` – membership status

## Operators Used

- `*` – multiplication
- `-` – subtraction
- `~/` – integer division
- `%` – remainder
- `<=` – comparison
